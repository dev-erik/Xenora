signed difference to the signed 32-bit range. Wrapping mode remains unchanged.

and 64-bit arithmetic. The primary reference widens to i64; the second reference
uses ripple subtraction and separate sign comparisons. Fixed expected words are

## Stage 3.1 increment: signed addition and byte permutation
